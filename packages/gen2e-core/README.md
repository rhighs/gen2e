# @rhighs/gen2e-core

This package holds the contracts shared by the [gen2e](https://github.com/rhighs/gen2e) packages:

- the static store interface and the cache key
- errors and the classifier for evaluation errors
- token pricing
- telemetry types

It has no runtime dependencies. Most users install `@rhighs/gen2e` instead of this package.
